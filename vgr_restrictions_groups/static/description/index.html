VGR Restricciones de Presupuestos

Descripción

Este módulo para Odoo 17.0 implementa restricciones de seguridad para controlar qué usuarios pueden crear productos y contactos en el sistema. La restricción se basa en la pertenencia a grupos de seguridad específicos.

Características principales

  • Grupo de seguridad para creación de productos
  • Grupo de seguridad para creación de contactos
  • Grupo de seguridad para modificación de presupuestos
  • Restricción a nivel de modelo para productos y variantes
  • Excepciones para usuario administrador

Requisitos

  • Odoo 17.0
  • Módulos base: sale, stock, account

Instalación

  1. Clona este repositorio en tu carpeta de addons personalizados de Odoo
  2. Actualiza la lista de aplicaciones
  3. Busca e instala el módulo "VGR Restricciones de Presupuestos"

Configuración

Después de instalar el módulo:

  1. Ve a Configuración > Usuarios y Compañías > Grupos
  2. Asigna usuarios a los grupos "Creador de Productos" y/o "Creador de Contactos" según necesites

Uso

Una vez configurado:

  • Solo los usuarios que pertenezcan al grupo "Creador de Productos" podrán crear nuevos productos
  • Solo los usuarios que pertenezcan al grupo "Creador de Contactos" podrán crear nuevos contactos
  • Los usuarios que intenten crear registros sin pertenecer al grupo correspondiente recibirán un mensaje de error
  • El usuario administrador siempre puede crear productos y contactos
